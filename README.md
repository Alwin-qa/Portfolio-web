# Alwin PP - Portfolio (React + Vite)

## Run
```
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

## Edit your content
All text lives in `src/data.js`. Update your LinkedIn URL there (`linkedin`).
Your resume is in `public/Alwin_PP.pdf` (replace it any time, keep the file name).

## Deploy
Upload the `dist` folder to Netlify, Vercel or GitHub Pages.
